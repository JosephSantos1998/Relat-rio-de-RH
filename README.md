# RH
Esse relatório é o resumo de funcionario que tem dentro da empresa.

📊 Power BI – Relatório de RH.
_____________________________________________________________________________________________________________________________________
Este projeto apresenta um dashboard desenvolvido no Power BI para uma empresa fictícia do setor de RH, analisando a performance dos funcionários da empresa nos ano 2000 até 2015.

🔎 Visão Geral do Projeto
_____________________________________________________________________________________________________________________________________
O objetivo do relatório é oferecer uma análise clara e visual sobre o desepenhos dos funcionários da empresa em determinados setores.  
Onde o responsável do RH identifique padrões de acordo com a visão da empresa na qual a empresa se identificar.
_____________________________________________________________________________________________________________________________________

📈 Principais Análises
_____________________________________________________________________________________________________________________________________
* Números de Funcionários da empresa ( Ativos, Contratações, Desligamentos) 

* Números de Funcionários da empresa por areá ( Adminitração, Comercial, Operações, Logistica e Financeiro)

* Nível de funcinários da empresa ( Analista, Estagiário, Coordenador, Gerente e Diretor).

* Análise do perfil do Funcionário. 
_____________________________________________________________________________________________________________________________________

🛠️ Ferramentas Utilizadas
_____________________________________________________________________________________________________________________________________
* Power BI Desktop
* Power Query
* Linguagem DAX
* Modelagem e tratamento de dados
